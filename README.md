# 🎵 Aura Music Player

A modern, responsive web-based music player built with HTML5, CSS3, and JavaScript. Inspired by modern streaming applications, this application features a dark-themed UI, dynamic track rendering, audio synthesis via Web Audio API, playlist navigation, progress tracking, and volume controls.

---

## 🚀 Features

- **Modern Dark Interface:** Sleek two-column desktop layout with a sidebar navigation, main content area, and a bottom audio dock.
- **Web Audio API Synthesizer:** Built-in audio engine that generates real sound programmatically, eliminating external audio hosting dependencies or CORS issues.
- **Audio Controls:**
  - Play / Pause toggles
  - Next / Previous track switching
  - Interactive seek progress bar
  - Adjustable volume slider
- **Interactive Playlist:** Dynamic track list rendering with active state highlights.
- **Autoplay Support:** Automatic transition to the next track upon completion.
- **Responsive & Accessible Design:** Clean font hierarchy using system sans-serif fonts and FontAwesome icons.
